# AI Thumbnail Generator — Girish AI Thumbnail & Content Suite

A client-side, no-backend web app for generating AI-style video thumbnails and content assets. Everything runs in the browser — zero setup, free, no sign-up.

## Features
- AI thumbnail generation UI with live preview
- Content-suite tools bundled in a single page
- Sparkle/particle animated background
- Tailwind CSS styling via CDN, responsive layout

## Tech Stack
- HTML5, CSS3, JavaScript (vanilla)
- Tailwind CSS (CDN)
- Google Fonts (Inter)

## Quick Start
```bash
git clone https://github.com/DevarshLade/AI-Thumbnail-Generator.git
cd AI-Thumbnail-Generator
# open in any static server
npx serve .
# or simply open index.html in a browser
```

## Project Structure
```
AI-Thumbnail-Generator/
├── index.html      # full app (markup, styles, scripts)
└── README.md
```

## Deploy Notes
Static single-page site — deploy anywhere static files are served (GitHub Pages, Cloudflare Pages, Netlify). No build step, no environment variables.
